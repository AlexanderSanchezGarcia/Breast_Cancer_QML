\section{Análisis Exploratorio de Datos}
\label{sec:eda}

% fuente: H-001, H-010, D-012
El análisis exploratorio de datos (EDA) se realizó sobre
el dataset CBIS-DDSM completo, procesando los cuatro
archivos CSV y enlazándolos con los 3\,568 archivos DICOM
del dataset, descargados con el NBIA Data Retriever salvo
84 series que se recuperaron después mediante la API REST
de TCIA. El análisis se organiza en cuatro bloques:
validación y saneamiento de los datos, análisis de la
variable objetivo, análisis de variables clínicas, y
análisis de las imágenes DICOM. Todos los resultados
descritos en esta sección fueron obtenidos mediante el
notebook \texttt{1\_EDA.ipynb} disponible en el
repositorio del proyecto.
